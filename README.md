# Snake.repo
Snake Game 

Both files [snake_game] and [bot.py] were placed in a folder together, with a common virtual environment for both files. 
Only the bot.py file was edited with various modification to get the best scores in the snake game from repetitive training. 

By implementing TensorFlow with two dense layers, changes to the directions of the snake_bot along with the reward system [food iver survivial].
With the help of ChatGPT, I was able to implement these different strategies and explore the different options and paths I could take to get better results. I also learned more in depth about what each line of code meant in the model which helped me to make decisions on what to change without the help of ChatGPT. 
As a result from various adjustments from the code, my highest score was 24.
