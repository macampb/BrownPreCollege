# MNIST.repo
Image processing - MNIST
To create the MNIST code, I used a guide generated by ChatGPT using PyTorch.
I installed a virtual environment for the file and pip installed various packages in order for the model to successfully run. 
In the model, I used CNN with 4 inner layers (I believe) in the Neural Network Model but 8 total layers in the MNIST overall.

After repetitive training, My highest accuracy was 99.00% where my lowest was 98.79%
In order to improve the accuracy, I had to implement early stopping to prevent overfitting of data.
