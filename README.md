# Eng2French
English to French AI Translator 
In order to successfully run/code this English to French AI Translator, this was the step-by-step process taken.
Firstly I had to download Python 3.11.9 in order to be compatible with TensorFlow and PyTorch
After that, I opened VS code, opened the code and immediately installed a virtual environment for the code. 
Following the installation, installed various packages onto my virtual environment in order for the code to work properly and run. This included numpy, helper and tensorflow. 
With the help of ChatGPT, I was able to pinpoint errors and make adjustments to allow the code to begin training. 
After training for some hours, I was finally able to use the translator.
Unfortunately, the translator was not accurate due to the lack of data the model was trained on.
To improve the model, I would train the model on more datasets of English to French sentences [especially basic sentences] to improve translation accuracy.
