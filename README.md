# IMDB.repo
Sentiment Classification - Internet Movie Database for training. 

This code was used in a Sentiment Classification Competition. 
Only the IMDB datasets were allowed to be used in training with no pre-trained models allowed. 

I used ChatGPT to create the code using IMDB datasets for training, using TensorFlow.
I also used Data Augmentation through the methods of random deletion and random swapping. 
I also implemented dropouts and early stopping for better accuracy. Additionally, layers such as embedding, conv1d, dense layering and lstm were used in the code.

In testing, the highest accuracy was 88.0%
ChatGPT was also used to fix coding errors and find different methods to improve training accuracy.
